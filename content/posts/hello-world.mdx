## 缘起

每一段代码旅程都从一句话开始：

```javascript
console.log("Hello, World!");
```

搭建这个博客的初衷很简单——我需要一个地方来记录技术笔记和折腾的过程。市面上的博客平台很多，但作为一个喜欢 terminal 风格的开发者，我决定自己动手。

## 为什么选择自建？

主要有几个原因：

1. **完全掌控** — 从样式到部署，一切由自己决定
2. **学习驱动** — 借这个项目深入了解 Next.js App Router
3. **极客美学** — 想要一个 terminal 风格的界面

## 技术栈

这个博客使用了以下技术：

```typescript
const techStack = {
  framework: "Next.js 16",
  styling: "Tailwind CSS 4",
  content: "MDX",
  highlighting: "Shiki + rehype-pretty-code",
  deployment: "Vercel",
};
```
